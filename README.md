# Бот-автопостер «Идея в кассу»

Каждый день по расписанию (по умолчанию 08:30, 11:30, 14:30, 17:30, 20:30 МСК) бот:

1. За час до слота читает свежие новости (РБК, vc.ru — список меняется в `.env`).
2. Просит GigaChat написать пост по рубрике: Идея дня, Без вложений, Ниша под лупой,
   Подсмотрено за рубежом, Разбор ошибок (рубрики сдвигаются по дням недели).
3. Подбирает фото на Pexels.
4. Присылает черновик всем админам в личку с кнопками:
   - **✅ В 14:30** — одобрить, пост выйдет в свой слот
   - **⚡ Сейчас** — опубликовать немедленно
   - **🔄 Текст** — переписать заново
   - **🖼 Фото** — другая картинка
   - **✏️ Править** — прислать свой текст следующим сообщением
   - **🗑 Удалить**

Не одобренный черновик в канал **не попадёт**.

Команды в личке с ботом: `/new` — черновик прямо сейчас, `/new 3` — конкретной рубрики,
`/queue` — очередь, `/cancel` — отменить правку.

## Установка

### 1. Ключи

| Что | Где взять |
|---|---|
| `MAX_TOKEN` | Кабинет бота в MAX для партнёров (можно отдельного бота для канала или бота компании) |
| `GIGACHAT_AUTH_KEY` | developers.sber.ru → GigaChat API → «Ключ авторизации» |
| `PEXELS_API_KEY` | pexels.com/api — бесплатно |

### 2. Сертификат Минцифры

GigaChat и API MAX работают на российском сертификате. Скачайте «Russian Trusted Root CA»
(страница «Сертификаты» на Госуслугах) и после шага 3 склейте его с обычными сертификатами:

```bash
cd /opt/vkasu-bot
cat $(venv/bin/python -c "import certifi; print(certifi.where())") russian_trusted_root_ca.crt \
    > /opt/vkasu-bot/russian_trusted_root_ca.pem
```

Путь к получившемуся файлу укажите в `CA_BUNDLE`.

### 3. Файлы на сервер

```bash
sudo mkdir -p /opt/vkasu-bot && cd /opt/vkasu-bot
# скопируйте сюда bot.py, requirements.txt, .env.example
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env   # впишите ключи
```

Нужен Python 3.9 или новее.

### 4. ID канала и админов

1. Добавьте бота **администратором канала** с правом публиковать посты.
2. `venv/bin/python bot.py chats` — покажет ID канала, впишите в `CHANNEL_ID`.
3. Каждый админ пишет боту в личку любое сообщение — бот ответит его ID.
   Впишите ID через запятую в `ADMIN_IDS`.

### 5. Проверка

```bash
venv/bin/python bot.py test
```

Админам должен прийти черновик. Затем запустите бота, чтобы заработали кнопки:

```bash
venv/bin/python bot.py
```

### 6. Автозапуск (systemd)

```bash
sudo cp vkasu-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now vkasu-bot
journalctl -u vkasu-bot -f     # смотреть логи
```

## Настройка

- **Время и количество постов** — `SLOTS` в `.env`.
- **Стиль текста** — `SYSTEM_PROMPT` в начале `bot.py`.
- **Рубрики** — список `RUBRICS` там же.
- **Источники новостей** — `RSS_FEEDS`, любые RSS-ленты через запятую.

## Если что-то не работает

- `SSL: CERTIFICATE_VERIFY_FAILED` — проверьте шаг 2 и путь в `CA_BUNDLE`.
- `401` от MAX — неверный `MAX_TOKEN`.
- Пост не публикуется в канал — бот не админ канала или неверный `CHANNEL_ID`.
- `402` от GigaChat — закончились токены на балансе.
